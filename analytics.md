# Analytics

## Overview

The Analytics module provides insights into user behavior, engagement, retention, and campaign performance.

It helps teams understand how users interact with products and services.

## Available Components

### User Profiles

View individual user information, activity history, attributes, and engagement details.

### Events

Track and analyze user actions recorded across the platform.

### Funnels

Analyze user progression through defined conversion steps and identify drop-off points.

### Cohorts

Group users based on common characteristics or actions for retention and behavior analysis.

### Pivots

Perform multidimensional data analysis using configurable dimensions and metrics.

### Power Curve

Analyze user activity distribution and identify engagement patterns across user groups.

## Benefits

* Understand user behavior
* Measure campaign effectiveness
* Improve user retention
* Identify growth opportunities
* Support data-driven decision making

## Best Practices

* Define clear business metrics.
* Regularly review funnel performance.
* Monitor retention cohorts.
* Validate event tracking accuracy.
