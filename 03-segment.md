# Segment

## Overview

The Segment module enables users to create and manage audience groups based on user attributes, behaviors, and real-time activities.

Segments are used across GrowthRx for targeting, analysis, campaign execution, and user engagement workflows.

## Segment Types

### Behaviour Segment

Behaviour segments are executed on the server and are based on user actions, events, and historical activity patterns.

### Live Segment

Live segments are evaluated in real time and can be used for immediate targeting and in-app engagement use cases.

### Custom Segment

Custom segments allow audience creation through uploaded datasets and custom criteria.

## Use Cases

* Campaign targeting
* User engagement
* Personalization
* Audience analysis
* Journey execution

## Best Practices

* Use meaningful segment names.
* Review segment logic before activation.
* Avoid duplicate audience definitions.
* Regularly validate segment counts.
