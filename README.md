# GrowthRx Documentation

Welcome to the official GrowthRx documentation portal.

## Overview

GrowthRx is an internal customer engagement and analytics platform that helps teams understand user behavior, create audience segments, automate communication, and measure campaign performance.

The platform provides tools for segmentation, notifications, analytics, journey automation, and reporting through a unified interface.
