# Notifications

## Overview

The Notifications module enables communication with users across multiple channels from a single platform.

Users can create, schedule, and monitor campaigns using various notification channels.

## Available Channels

### Push Notification

Send standard push notifications to users on supported devices.

### Rich Push Notification

Send enhanced push notifications with images, actions, and rich content.

### E-mail Notification

Create and send email campaigns to targeted user segments.

### In-app Notification

Display notifications directly within the application interface.

### SMS Alerts

Send text-based alerts and updates to users.

### Rich Content SMS

Send SMS messages containing dynamic and personalized content.

### WhatsApp Notification

Reach users through WhatsApp-based communication workflows.

### Liquid Tags

Liquid Tags enable dynamic personalization within campaign content by replacing placeholders with user-specific values.

## Common Use Cases

* User engagement campaigns
* Promotional messaging
* Transactional notifications
* Product updates
* Personalized communication

## Best Practices

* Target the correct audience segment.
* Preview campaigns before sending.
* Use personalization wherever possible.
* Monitor delivery and engagement metrics.
