# Journey

## Overview

Journey is an automation module that enables communication with users based on their actions, behaviors, and predefined conditions.

It helps deliver the right message at the right time through channels such as Email, Push Notifications, SMS, and WhatsApp.

## Core Components

### Trigger

Defines when the journey starts.

Examples:

* User Registration
* Page View
* Payment Success
* Scheduler

### Condition

Determines which users continue in the journey.

Examples:

* Have Filter
* Have Not Filter
* Segment
* A/B Test
* Timezone

### Action

Defines what happens next.

Examples:

* Email
* Push Notification
* SMS
* WhatsApp
* In-App Notification

## Common Use Cases

* User onboarding
* Payment reminders
* Re-engagement campaigns
* Personalized offers
* Behavioral targeting

## Key Benefits

* Automated communication
* Multi-channel engagement
* Improved user retention
* Personalized customer experience

## Reporting

Journey reports provide visibility into user flow progress and journey performance through real-time metrics and status tracking.
